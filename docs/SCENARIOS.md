# 异常场景清单与验收

## 使用约定

- **展示位置**：本机制新增的处理 / 异常状态及恢复按钮统一在左侧控制台结果区展示；不在手机中增加弹窗、遮罩、提示条，不抢产品输入焦点。原 Demo 自有的业务提醒 / 抽屉不变。隐藏后场景仍生效，需要恢复时重新打开控制台。

- **N：下一次操作触发**（默认）。先设置，再从产品界面执行下表操作；先进入等待，再出现异常 / 空态。不会在失败后继续执行成功逻辑。
- **P：直接预览**。自动导航到对应环节、准备最小本地上下文，在旁边结果区立即展示异常 / 空态；持续加载和弱网则预览等待过程。不会自动成功提交。点击明确的恢复按钮后才执行本地模拟业务。
- N 可选**仅一次 / 持续生效**。仅一次在匹配操作开始时消费，控制台区分“待触发”和“当前已触发”。持续生效在本次重试成功后仍会影响下一次新操作。
- 错误 / 空态均可设置**重试后成功 / 重试后继续失败**。加载态通过取消退出；取消后可恢复正常再重新操作。弱网 N 延迟 5 秒后成功，可提前取消。
- 所有状态都有“取消，返回当前页面”或“取消等待”，以及返回设备入口的退出路径。取消不会提交；同页表单草稿保留。主动离开未保存表单视为放弃草稿。
- 默认失败等待约 1.4 秒，超时约 4.5 秒；持续加载不会自动结束。正常调奶仍等待约 4 秒，其他模拟操作按原业务配置。

## 21 个可复现场景

| --- | --- | --- | --- | --- | --- |
| 设备列表 `devices.loading` | 持续加载中 | 进入设备列表或点重新加载设备 | 一直查找，不展示已成功列表 | 取消等待 → 恢复正常 → 重新加载设备 | N / P |
| 设备列表 `devices.empty` | 没有可用设备 | 加载 / 重新加载设备 | 等待后空态，不删除其他模拟数据 | 重新查找 → 返回 FD04 样例设备；或取消 | N / P |
| 设备列表 `devices.failure` | 请求失败 | 加载 / 重新加载设备 | 等待后加载失败 | 重试 → 正常设备列表；可继续失败或返回 | N / P |
| 调奶 / 出水 `preparation.water` | 水量不足 | 选择水量、温度后点击开始；奶粉模式先配置配比 | 设备检查失败，不出水、不扣原料、不新增记录 | 已补水，重新开始 → 本次成功后才出结果；设置保留 | N / P |
| 调奶 `preparation.powder` | 出粉异常 | **奶粉模式**且已配置配比，点击开始 | 出粉检查失败，中止，不扣原料或记录成功 | 已检查，重新开始 → 重新执行并记录一次；可取消 | N / P |
| 调奶 / 出水 `preparation.timeout` | 设备响应超时 | 点击开始 | 等待约 4.5 秒后超时，无成功结果 | 确认状态后重试；或取消回控制页 | N / P |
| 拍摄 `capture.permission` | 相机权限拒绝（模拟） | 正面 / 侧面取景页点击快门 | 等待后拒绝，不修改系统权限、不继续识别 | 模拟允许并重试 → 继续原拍摄流程；或改为手动输入 | N / P |
| 拍摄 `capture.upload` | 照片上传失败 | 点击快门 | 上传等待后失败，模拟照片保留，尚未提交配比 | 使用同一模拟照片重试 → 正面下一步 / 侧面配比编辑；或手动 | N / P |
| 识别 `capture.recognition` | 配比识别失败 | **侧面 / 背面**取景页点击快门 | 模拟上传完成后识别失败，无配比提交 | 重试识别 → 带样例配比的编辑页；或手动填写 | N / P |
| 拍摄 `capture.loading` | 上传持续等待 | 点击快门 | 一直等待上传，不继续成功流程 | 取消 → 重新拍摄；可恢复正常再提交 | N / P |
| 配比 `formula.save` | 配比保存失败 | 填入有效配比，点击确认 / 保存 | 等待后保存失败，原配比及表单仍保留 | 重试成功才写入；或返回修改输入再保存 | N / P |
| 配比 `formula.validation` | 业务校验失败 | 填入本地合法配比后点击保存 | 模拟校验服务拒绝，不写入 | 修改配比再提交；重试成功代表模拟校验通过 | N / P |
| 设备同步 `sync.failure` | 配比同步失败 | 同步提醒 → 选择配比 → 确认同步 | 等待后失败，所选配比不被覆盖 | 重试成功才写入机器端样例比例；取消保留选择 | N / P |
| 设备同步 `sync.timeout` | 同步响应超时 | 选择配比并确认同步 | 约 4.5 秒后超时，目标及原数据保留 | 重试完成同步；或取消回选择列表 | N / P |
| 清洁 `cleaning.interrupt` | 清洁操作中断（模拟） | 选择模式、完成准备、点击开始清洁 | 模拟启动 / 连接检查中断，不能进入完成态 | 重新检查并开始 → 原正常第一阶段；或取消 / 退出 | N / P |
| 清洁 `cleaning.timeout` | 清洁启动超时 | 点击开始清洁（包括提醒页自动启动） | 等待后设备未确认启动，不标记完成 | 重试从准备条件重新启动；或退出 | N / P |
| 喂养 `feeding.empty` | 暂无记录 | 进入统计页或重新加载记录 | 等待后空态，不删除已保存记录 | 添加第一条记录 → 表单；或重新加载初始样例 / 保存记录 | N / P |
| 喂养 `feeding.load` | 记录加载失败 | 加载 / 重新加载记录 | 加载失败，不覆盖已有记录 | 重试恢复列表；或取消 / 返回设备页 | N / P |
| 喂养 `feeding.save` | 记录保存失败 | 填写奶量、时间、喂养人 / 备注后保存 | 等待后失败，所有输入保留，不新增记录 | 返回修改输入；或重试成功后只新增一次并回统计页 | N / P |
| 全局 `global.offline` | 断网（模拟） | 下一个接入的模拟服务 / 设备操作 | 等待后失败，不能执行成功提交；不影响页面浏览 | 模拟重连并重试；或恢复正常后主动重新操作 | N / P |
| 全局 `global.weak` | 弱网（模拟） | 下一个接入的模拟服务 / 设备操作 | N 等待 5 秒后成功；P 只预览等待、不自动提交 | 等待完成，或取消等待后重新操作 | N / P |

系统权限、上传、识别、设备响应及网络行为均为**模拟**，不依赖真实故障。不存在真实登录流程，未添加登录失效。出水模式不会触发出粉异常；正面拍摄不消费识别失败场景。

## 推荐演示脚本

### 1. 真实操作触发 + 一次消费

完整重置 → 正常配置配比 → 设置调奶「水量不足 / 下一次 / 仅一次 / 重试后成功」→ 隐藏控制台 → App 点击开始 → 看到等待及异常 → 检查记录未增加 → 已补水重新开始 → 成功结果、记录和原料扣减只发生一次。

### 2. 草稿保留 + 持续失败

配比编辑填入品牌 → 设置保存失败 / 持续 / 重试继续失败 → 保存失败 → 重试仍失败 → 返回修改输入（草稿不变）→ 控制台恢复正常（不自动保存）→ 主动保存成功。

### 3. 清洁恢复 + 计时器重置

清洁 → 深度除垢 → 继续确认 → 准备步骤继续 → 设置清洁中断 → 开始清洁 → 异常 → 重新检查并开始 → 第一阶段完成 → 按页面准备第二阶段 → 完成。再次开始后重置当前环节，等待超过原流程时长也不会跳回旧进度。

### 4. 全局环境互斥

先设置配比保存失败，再设置全局断网，局部场景被清除；提交任一已接入业务操作都显示断网。全局仍生效时局部设置按钮禁用。点击恢复正常不自动保存，必须回 App 主动重试 / 提交。

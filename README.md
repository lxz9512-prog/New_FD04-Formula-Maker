## 30 秒演示一次异常

1. 桌面端使用目录与手机之间的左侧控制台；移动端点击底部「场景控制台」打开抽屉。
2. 在「流程环节」选择 **配比编辑 / 保存**，点击「准备最小演示数据并进入此环节」。
3. 选择 **配比保存失败**，保持默认「下一次操作触发」「仅一次」「重试后成功」，点击「设置下一次操作场景」。
4. 在 App 中点击确认保存：左侧控制台先显示处理过程，再显示失败，**不会提前保存**。手机内不添加演示专用弹窗；也可先隐藏控制台触发，再打开查看结果。
5. 在控制台结果区点击「返回修改输入」检查草稿仍保留；或点击「重试」，成功后才保存并返回配比列表。

也可用「直接预览」快速检查任一异常状态：自动进入对应页面并准备最小模拟上下文，不自动执行成功写入。控制台结果区的「重试」是明确的恢复操作，会执行真正的本地模拟业务。

## 控制台行为

- 浅暖色工具面板与产品界面分开；支持收起、隐藏。隐藏后待触发 / 持续场景仍有效；模拟结果与恢复按钮仅在旁边的控制台展示，不抢焦点、不自动弹出，不改变原产品弹窗。
- 按 7 个业务环节分组；断网、弱网独立归入全局环境。拍摄正面不提供识别失败，喂养列表与记录表单按当前步骤区分。
- 默认「下一次操作触发」；「仅一次」匹配后消费，「持续生效」用于后续每次新操作。
- 重试策略属于本次失败链路：成功 / 继续失败。持续场景即便本次重试成功，下一次新操作仍会触发。
- 全局环境与局部注入互斥：设置全局会清除局部，生效时不能叠加局部，需先恢复正常。
- **恢复正常**：清除注入并取消当前模拟等待 / 异常，不自动提交、不重放操作。
- **重置当前环节**：清除该环节模拟数据和注入，取消等待，回到该环节入口；保留无关环节数据和全局环境。
- **重置整个 Demo**：清除本副本全部模拟数据和全局环境，回到设备列表，恢复默认语言 / 单位。
- 刷新或重新打开默认无异常注入；本地业务样例数据可保留，点击完整重置可回到首次状态。

数据隔离：本副本仅读写 `New_FD04_demo_v1:` 前缀下的 localStorage / sessionStorage；不会读取或清除原 Demo 的同名业务键。
